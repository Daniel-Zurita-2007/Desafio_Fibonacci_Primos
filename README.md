# 💰 Sistema de Ahorro Inteligente con Fibonacci y Números Primos

## 📌 Descripción del Proyecto

Este proyecto es una página web interactiva desarrollada con HTML, CSS y JavaScript.

El objetivo del sistema es ayudar a las personas a mejorar sus hábitos de ahorro utilizando la serie de Fibonacci y los números primos.

La aplicación permite ingresar una cantidad de meses y genera automáticamente un plan de ahorro progresivo.

Además, identifica cuáles meses son números primos y los marca como meses especiales de ahorro.

---

# 🌍 Problema del Mundo Real

Muchas personas desean ahorrar dinero, pero no saben cuánto ahorrar cada mes o abandonan el hábito rápidamente.

Este proyecto propone una solución sencilla y progresiva usando patrones matemáticos.

La serie de Fibonacci permite aumentar el ahorro poco a poco, mientras que los números primos ayudan a identificar meses especiales para motivar un ahorro adicional.

---

# 🔢 Explicación del Algoritmo

## Serie de Fibonacci

La serie de Fibonacci es una secuencia matemática donde cada número se obtiene sumando los dos anteriores.

Ejemplo:

1, 1, 2, 3, 5, 8, 13...

En este proyecto, cada número representa el dinero ahorrado en cada mes.

---

## Números Primos

Un número primo es aquel que solo puede dividirse exactamente entre 1 y sí mismo.

Los meses primos son considerados meses especiales de ahorro dentro del sistema.
