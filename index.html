💰 Sistema de Ahorro Inteligente

Aplicando la Serie de Fibonacci y los Números Primos para mejorar los hábitos de ahorro.

📌 Problema del Mundo Real

Muchas personas desean ahorrar dinero, pero no saben cuánto ahorrar cada mes o abandonan el hábito rápidamente.

Este proyecto propone un sistema de ahorro progresivo utilizando la serie de Fibonacci para aumentar el ahorro poco a poco.

Además, se utilizan los números primos para identificar meses especiales donde el usuario recibe una recomendación de ahorro adicional.

📚 Explicación del Algoritmo

🔢 Serie de Fibonacci

La serie de Fibonacci es una secuencia matemática donde cada número se obtiene sumando los dos anteriores.

1, 1, 2, 3, 5, 8, 13...

En este proyecto, cada número representa la cantidad de dinero que se ahorra en cada mes.

🟢 Números Primos

Un número primo es aquel que solo puede dividirse exactamente entre 1 y sí mismo.

Los meses primos serán considerados meses especiales de ahorro.
